# For Pallavi — customized background with her likes

This version uses a black & purple theme and a subtle animated background made from words describing what Pallavi likes:
- dosa
- black & purple
- Ramcharan
- travelling
- singing
- Arijit Singh

Files:
- index.html
- styles.css
- script.js
- placeholder.jpg (replace with a real photo)

How to preview
1. Put all files in the same folder.
2. Replace `placeholder.jpg` with a real photo of Pallavi (same filename) or update the <img> src in index.html.
3. Open `index.html` in a browser.

Notes and customization ideas
- To change which words appear in the background, edit the `tags` array in `script.js`.
- To make the background words subtler or more visible, adjust `--tag-opacity` in `styles.css`.
- If you want the heading changed to include her name (e.g., "Pallavi — is a good friend"), tell me and I'll update it.
- I can also convert the floating words to icons (food, travel, music, actor) if you prefer image/icon motifs instead of text.

Tell me if you'd like changes (word list, opacity, speed, colors, heading text, photo placement) and I'll update the files.
